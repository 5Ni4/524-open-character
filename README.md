### プロジェクトの考え

- 不思議生命体524 について、自由な創作を歓迎します。
- 原作者である R-524 本人が、 524 の原画をもとに AI生成しまくっているので、みなさんも気兼ねなくAIを利用して創作してください。
- みなさんのアイデアの一部を、[R-524](https://x.com/R5ni4)が公式設定や公式素材として選ぶことがあります。
- 524の創作物の権利は、それぞれの作者に帰属します。
- 他の人の524作品をAI生成に利用しても構いませんが、許されるレベル感を見極めてください（やるなら楽しくやって）
