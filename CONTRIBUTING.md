# Contributing to the 524 project

[日本語](CONTRIBUTING.ja.md) | English

Thanks for helping shape the project. Alternative interpretations and settings are welcome; an idea does not need to match the current official interpretation to be discussed.

## While the project is being set up

- Use an issue to discuss an idea, question, or possible direction.
- Issues and pull requests in this public repository are visible to everyone.
- Do not upload someone else's artwork, personal information, or material you do not have permission to publish.
- A proposal is not automatically licensed for reuse or adopted as official. The project will ask for explicit permission before reusing a fanwork, unless the creator has already opted in through a clearly described submission process.

The project will add submission instructions after the official-material license and fanwork-permission process are settled.
