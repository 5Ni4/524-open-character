# Project principles (draft)

## Many interpretations can coexist

524 can have many interpretations, alternate settings, and creative branches. The project does not need to reduce them all to one correct version.

## Official canon is a curated branch

R-524 may select some community ideas for official settings or materials. A proposal becomes official only when the project explicitly marks it as adopted. Not being adopted does not make an interpretation less welcome.

## Keep character permission and fanwork permission separate

The project intends to make use of 524's official character materials broadly available, including AI use. A creator's fanwork remains that creator's work. Permission to use 524 does not grant permission to reuse another person's specific fanwork.

## Credit creators

When a fanwork is included in the project or adopted into official materials with the creator's permission, the project intends to credit the creator and identify any changes.
