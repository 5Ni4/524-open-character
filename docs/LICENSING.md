# ライセンスと許可について（検討中の草案）

この文書には、現在検討している方針を記載しています。最終的なライセンスでも、包括的な利用許可でもありません。

## 524の公式素材

524の公式キャラクター素材をもとに、作品を作成・改変・公開・再配布できるようにすることを目指しています。商用利用とAI利用も認める方向で検討しています。具体的なライセンス、クレジット表記の方法、対象となる公式素材の範囲は、まだ決まっていません。素材ごとに条件を選び、明示する必要があります。

## 他の作者によるファン作品

ファン作品の権利は作者にあります。作品を公開したり、R-524をタグ付けしたり、アイデアを提案したりしただけでは、プロジェクトや他の人がその作品を使う許可にはなりません。

再利用には作者の許可が必要です。再利用には、コピーや転載、編集や再構成、ギャラリーへの掲載、公式設定や公式素材への採用、AIへの入力・学習・変換のための利用が含まれます。

今後、事前同意にもとづく応募方法を設ける可能性があります。たとえば、作者が応募時にギャラリー掲載や公式採用など特定の用途をあらかじめ許可し、その範囲内では個別に再確認しなくてもよい仕組みです。AI利用の許可と、他の人が広く再利用する許可は、分けて明記します。

## すでに公開されている投稿

すでに公開されている投稿が、自動的にプロジェクトに含まれたり、このリポジトリのライセンスで利用可能になったりすることはありません。紹介・採用したい作品について、明確な事前同意の手続きを設けます。

## これから決めること

- 524の公式素材に適用するライセンスと、その対象範囲。
- 公式素材の商用利用、クレジット表記、AI利用の説明方法。
- ファン作品について作者が許可できる用途（ギャラリー掲載、画像表示、公式採用、編集、AI利用、他の人による広範な再利用）。
- プロジェクトで今後利用するための許可を、作者がどのように付与・変更・撤回できるか。
