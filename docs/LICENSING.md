# Licensing and permissions (discussion draft)

[日本語](LICENSING.ja.md) | English

This document records the intended direction. It is not the final license or a blanket grant of permission.

## 524 official materials

The project intends to let people create, modify, publish, and redistribute works based on 524's official character materials. Commercial use and AI use are intended to be allowed. The exact license, attribution method, and scope of official materials still need to be selected and clearly attached to each asset.

## Fanworks by other creators

Fanwork creators retain rights in their own works. Publicly posting a work, tagging R-524, or suggesting an idea does not grant the project or other people permission to reuse it.

Reuse requires the creator's permission. This includes copying or reposting, editing or remixing, adding the work to a gallery, incorporating it into official canon or materials, and using it for AI input, training, or transformation.

The project may create an opt-in submission process. A creator could grant the project permission in advance for selected uses, such as gallery display or official adoption, so the project would not need to ask again for each use within that scope. Permission for AI use and permission for public reuse by other people will be stated separately.

## Existing posts

Existing public posts are not automatically included in the project or licensed by this repository. The project will use a clear opt-in process for works it wants to feature or adopt.

## Still to decide

- The license and exact scope for official 524 materials.
- How commercial use, attribution, and AI use are described for those materials.
- Which permissions a creator can grant for a fanwork: gallery listing, image display, official adoption, editing, AI use, or public reuse by others.
- How creators grant, change, or withdraw permission for future project uses.
