# 未決定の事項

[English](DECISIONS.md)

## 現在の方針

- 524について、さまざまな解釈や別設定を歓迎します。
- コミュニティのアイデアの一部を公式設定に採用することがあります。採用したものはプロジェクト内で明示します。
- 524の公式素材は、AI利用も含め幅広く再利用できる形を目指します。
- ファン作品の再利用は作者の許可を前提とします。他の人のファン作品を使うには、その作者の許可が必要です。
- 公式採用を検討する作品の応募時に、作者が特定の用途についてプロジェクトへ事前許可を与えられる仕組みを設ける可能性があります。

## これから決めること

- プロジェクトとリポジトリの正式名称。
- 公式キャラクター素材と参考素材に適用するライセンス。
- 必要なクレジット表記と、非公式作品であることの示し方。
- 公式素材の商用利用を無制限にするか、AI利用をどう説明するか。
- 公式採用候補作品の応募方法。
- ファン作品について許可を得る用途（ギャラリー掲載、公式採用・編集、AI利用、他の人による広範な再利用）。
- 公式・別設定の区分や変更履歴のバージョン管理方法。
- 提案を審査し、リポジトリを管理する担当者。
